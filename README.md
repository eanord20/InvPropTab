# InvPropTab

InvPropTab — надстройка для Autodesk Inventor 2020, добавляющая в браузер документа панель просмотра и редактирования iProperties.

## Текущее состояние

Проект находится в подготовке к первому публичному выпуску. Поддерживается Autodesk Inventor 2020 x64 на Windows.

## Требования для сборки

- Windows x64
- Autodesk Inventor 2020
- .NET Framework 4.8 Developer Pack
- Visual Studio 2022 или совместимый MSBuild

Подробные инструкции по сборке, установке и настройке будут добавлены в ходе подготовки выпуска.
