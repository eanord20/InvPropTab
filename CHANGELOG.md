# Changelog

## 1.1.0

- Добавлена кнопка «Открыть чертёж» рядом с именем файла в панели iProperties.
- Добавлено открытие связанного чертежа по двойному клику на имени файла.
- Исправлена синхронизация списков значений между несколькими открытыми документами.
- Снижены микролаги при переключении документа за счёт кэширования чтения history-файлов.

## 1.0.2

- Добавлена настраиваемая панель iProperties для Inventor 2020.
- Добавлен каталог стандартных свойств и настройка видимости/порядка.
- Добавлено запоминание и редактирование значений списочных полей.
- Отключено запоминание Description.
- Возвращена подсветка изменённых значений.
- Добавлены имя файла, габариты и масса.
- Добавлены импорт, экспорт и восстановление конфигурации.
- Добавлен per-user установщик Inno Setup без прав администратора.
- Улучшены COM lifecycle и диагностика.
