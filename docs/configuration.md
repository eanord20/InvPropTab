# Настройка полей

Нажмите «Настроить» внизу панели.

## Доступные действия

- «Показывать» включает поле в панели;
- «Вверх» и «Вниз» меняют порядок;
- «Запоминать» разрешает сохранять введённые значения списочного поля;
- «Значения…» открывает редактор сохранённых вариантов;
- «Импорт» и «Экспорт» переносят конфигурацию JSON;
- «По умолчанию» возвращает заводской набор.

Description всегда остаётся обычным текстовым полем и не сохраняет историю.

## Редактор значений

Редактор можно открыть:

- кнопкой `…` рядом со списочным полем;
- через окно настройки кнопкой «Значения…».

Поддерживаются добавление, изменение, удаление и очистка. Пустые значения и дубликаты без учёта регистра не сохраняются.

## Файл конфигурации

Путь: `%APPDATA%\InvPropTab\fields.json`.

Не рекомендуется менять файл вручную при запущенном Inventor. Повреждённый файл не перезаписывается автоматически; программа загружает заводскую конфигурацию и записывает проблему в журнал.
