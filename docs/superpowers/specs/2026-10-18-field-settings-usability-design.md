# InvPropTab: упрощение настройки полей и UX панели

## Статус

Дизайн утверждён 18 октября 2026 года. Изменения предназначены для Autodesk Inventor 2020 x64.

## Цели

- Исправить запоминание введённых значений для списочных полей, включая «Поставщик».
- Заменить техническую таблицу настройки на понятный список свойств Inventor.
- Вернуть светло-зелёную подсветку изменённых значений до применения.
- Показывать имя файла с расширением под расположением документа.

## Причины текущего поведения

`rememberValues` сохраняется в модели поля и загружается в `ComboBox`, но после успешной записи новое значение не добавляется в `FieldDefinition.Values`. Динамические редакторы отслеживают отличие от исходного значения, однако не подписываются на пользовательские изменения и не изменяют цвет фона. Окно настройки напрямую показывает внутреннюю модель `FieldDefinition`, поэтому требует знания ID, source, PropertySet и имени iProperty.

## Каталог свойств

Программа содержит внутренний каталог стандартных свойств, соответствующий выбору столбцов спецификации Inventor 2020. Каждая запись каталога определяет:

- стабильный ID;
- русскую подпись;
- внутренний идентификатор PropertySet;
- имя iProperty или системный вычислитель;
- допустимый тип редактора;
- возможность запоминания значений;
- заводской порядок и видимость.

Первая версия каталога включает свойства, показанные Inventor в списке столбцов спецификации: веб-сайт, величина элемента, даты, имя файла, категория, ключевые слова, масса, материал, наименование, отделы, нормоконтроль, объём, организация, основная величина, поставщик, пояснения, представление, проверил, проект, путь файла, разработал, сметная стоимость, счётчик, стадия, статус, структурная единица, тема, тип компонента и утвердил. Существующие Part Number и Description сохраняются. Недоступные для конкретного документа свойства отображаются пустыми; ошибка одного свойства не блокирует панель.

## Окно настройки

Окно содержит один список. В каждой строке показываются:

- флажок видимости;
- русское название свойства;
- флажок «Запоминать»;
- текущая позиция, определяемая порядком строк.

Кнопки:

- «Вверх»;
- «Вниз»;
- «Импорт»;
- «Экспорт»;
- «По умолчанию»;
- «Сохранить»;
- «Отмена».

Пользователь не видит и не редактирует ID, source, PropertySet ID, propertyName и editor. Произвольные технические поля в первой версии нового окна не создаются. Импорт старой корректной конфигурации поддерживается: известные свойства сопоставляются с каталогом, неизвестные сохраняются в JSON, но в простом окне не редактируются и не включаются автоматически.

Флажок «Запоминать» доступен только у списочных редактируемых полей. Для Description он всегда выключен и недоступен.

## Запоминание значений

После успешной записи поля программа:

1. проверяет `editor == list` и `rememberValues == true`;
2. обрезает пробелы и игнорирует пустое значение;
3. добавляет значение без дублирования с учётом регистра;
4. сортирует список в текущей культуре;
5. обновляет элементы соответствующего ComboBox;
6. один раз атомарно сохраняет изменённую конфигурацию после обработки всех полей.

При ошибке записи значение не добавляется. Description не сохраняется в историю независимо от импортированной конфигурации.

## Подсветка изменений

`FieldEditorBinding` хранит исходный цвет и управляет dirty-состоянием. Фабрика подключает `TextChanged` для текстовых редакторов и `TextChanged`/`SelectionChangeCommitted` для списков.

Правила:

- пользовательское отличие от исходного значения окрашивает редактор в единый светло-зелёный цвет;
- программная загрузка документа не окрашивает поле;
- успешная запись принимает новое исходное значение и возвращает исходный цвет;
- ошибка записи оставляет значение и подсветку;
- переключение документа полностью сбрасывает dirty-состояние.

Цвет задаётся одной константой UI, а не копируется по компонентам.

## Имя файла

Под строкой «Расположение» добавляется read-only строка «Имя файла».

- Для сохранённого документа используется `Path.GetFileName(Document.FullFileName)`.
- Для несохранённого документа используется `Document.DisplayName`.
- Значение включает расширение.
- Поле очищается при отсутствии активного документа.

## Ошибки и диагностика

Ошибки чтения отдельных свойств записываются в журнал без модального окна. Ошибки применения показываются одним итоговым сообщением и остаются подсвеченными. Ошибка сохранения истории не должна отменять уже записанное iProperty, но должна попасть в журнал и итоговое сообщение.

## Тестирование

Автоматические тесты проверяют:

- новое значение Supplier сохраняется при `rememberValues=true`;
- дубликаты без учёта регистра не создаются;
- значение не запоминается после ошибки записи;
- Description никогда не запоминается;
- dirty-состояние и цвет появляются после пользовательского изменения;
- программная загрузка не создаёт dirty-состояние;
- успешное применение сбрасывает подсветку;
- ошибка применения сохраняет подсветку;
- каталог содержит уникальные ID и валидные определения;
- имя файла извлекается с расширением;
- несохранённый документ использует DisplayName.

Ручная проверка в Inventor 2020 охватывает деталь, сборку, документ только для чтения, переключение документов, изменение порядка, восстановление настроек и повторный запуск Inventor.

## Критерии готовности

- Введённый поставщик появляется в списке после применения и перезапуска Inventor.
- Окно настройки не показывает технические идентификаторы.
- Пользователь выбирает свойства из каталога, аналогичного списку столбцов спецификации.
- Изменённые значения подсвечиваются до успешного применения.
- Под расположением показывается имя файла с расширением.
- Все автоматические тесты и Release-сборка проходят без предупреждений.
