# InvPropTab: компоновка панели и редактор списков

## Статус

Дизайн утверждён 18 октября 2026 года. Выбран вариант A — локальные изменения существующей динамической панели без смены архитектуры.

## Верхняя часть панели

Подписи «Расположение» и «Имя файла» удаляются. Значения остаются двумя строками:

```text
[ C:\Projects\Assembly                         ][ открыть ]
[ 6675.01.01.001.ipt                                      ]
```

Путь и имя файла остаются read-only. Кнопка открытия папки сохраняется справа от пути.

## Панель свойств

Внешняя подпись «Свойства» удаляется. Состав, порядок и логика обычных динамических полей не меняются.

## Габариты и масса

Логика вычисления, единицы измерения и read-only поведение не меняются. Меняется только расположение: элементы находятся рядом в одной горизонтальной строке.

Порядок фиксирован:

```text
Габариты                         Масса
[ 100 × 50 × 20 мм ]             [ 12.5 kg ]
```

Слева находятся габариты, справа — масса. Между колонками используется стандартный отступ. При изменении ширины панели обе колонки занимают по 50% доступного пространства.

## Кнопки действий

«Настроить» и «Применить» находятся в одной горизонтальной строке:

```text
[ Настроить ]                         [ Применить ]
```

«Настроить» прижата к левому краю, «Применить» — к правому. Высота кнопок одинакова. Логика обработчиков не меняется.

## Редактирование сохранённых значений

Используется один общий диалог редактирования значений списочного поля. Диалог содержит список и действия:

- добавить;
- изменить;
- удалить;
- очистить;
- сохранить;
- отменить.

Диалог открывается двумя способами:

1. кнопкой `…` справа от списочного редактора основной панели;
2. кнопкой «Значения…» для выбранного списочного свойства в окне настройки.

Для полей не типа `list` действия недоступны. Для Description история всегда запрещена. После сохранения обновляются `FieldDefinition.Values`, активный ComboBox и `%APPDATA%\InvPropTab\fields.json`; перезапуск Inventor не требуется.

Отмена не меняет конфигурацию. Пустые значения не сохраняются. Дубликаты без учёта регистра не создаются. Значения сортируются в текущей культуре.

## Сокращение каталога

Из `InventorPropertyCatalog` удаляются:

- Дата проверки (`checkingDate`);
- Дата создания (`creationDate`);
- Веб-сайт (`webLink`);
- Тема (`subject`);
- Величина элемента (`itemQuantity`);
- Основная величина (`baseQuantity`);
- Тип компонента (`componentType`);
- Представление (`representation`).

При слиянии старой пользовательской конфигурации эти восемь известных удалённых ID не сохраняются как неизвестные поля. Другие неизвестные импортированные поля продолжают сохраняться скрыто, как определено предыдущей спецификацией.

## Запоминание для любого свойства

Флажок «Запоминать» доступен для любого редактируемого свойства независимо от его видимости. Исключения: Description, системные поля и read-only редакторы.

При включении флажка редактор свойства меняется с `text`, `multiline` или `number` на `list`. При выключении редактор возвращается к заводскому типу из `InventorPropertyCatalog`. Сохранённые `Values` не удаляются и восстанавливаются после повторного включения. Кнопка «Значения…» доступна только при включённом запоминании.

## Вертикальные отступы и «Прочее»

Между последним динамическим свойством, строкой габаритов/массы и таблицей пользовательских свойств используется один стандартный отступ без дополнительного пустого пространства. Заголовок «Прочее» удаляется; DataGridView добавляется в layout напрямую без внешнего Label. Высота таблицы сохраняется.

## Тестирование

Автоматические тесты проверяют:

- удалённые ID отсутствуют в каталоге;
- удалённые ID не возвращаются из старого `fields.json`;
- редактор списка нормализует, сортирует и удаляет значения;
- отмена не меняет исходный список;
- сохранение обновляет конфигурацию и активный ComboBox;
- скрытое редактируемое поле можно переключить `text ↔ list` флажком «Запоминать»;
- Description и read-only поля нельзя переключить в список;
- сохранённые значения не удаляются при выключении запоминания;
- кнопка значений доступна только при включённом запоминании;
- layout содержит одну строку габаритов и массы в правильном порядке;
- layout содержит одну строку кнопок в правильном порядке;
- подписи «Расположение», «Имя файла» и «Свойства» отсутствуют.

## Критерии готовности

- Путь и имя файла показаны без подписей.
- Габариты находятся слева, масса справа в одной строке.
- «Настроить» и «Применить» находятся в одной строке.
- Сохранённые значения можно редактировать из панели и настроек.
- Восемь исключённых свойств отсутствуют в настройках после обновления старой конфигурации.
- Тесты и Release-сборка проходят без предупреждений.
