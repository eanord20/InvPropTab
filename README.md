# InvPropTab

InvPropTab — надстройка для Autodesk Inventor 2020, добавляющая в браузер документа панель просмотра и редактирования iProperties.

## Возможности

- редактирование стандартных iProperties;
- настройка видимости и порядка полей;
- списочные поля с автодополнением;
- запоминание введённых значений;
- импорт, экспорт и восстановление настроек;
- подсветка изменённых данных до применения;
- отображение пути, имени файла, габаритов и массы.
- открытие связанного чертежа (.idw/.dwg) рядом с именем файла.

## Требования

- Windows x64;
- Autodesk Inventor 2020 x64;
- .NET Framework 4.8.

## Установка

1. Закройте Autodesk Inventor.
2. Запустите `InvPropTab-1.0.2-x64.exe`.
3. Запустите Inventor и откройте деталь или сборку.

Установка выполняется для текущего пользователя без прав администратора. DLL размещается в `%LOCALAPPDATA%\Programs\InvPropTab`, manifest — в `%APPDATA%\Autodesk\Inventor 2020\Addins`.

## Настройка полей

Нажмите «Настроить». В окне можно:

- включать и скрывать свойства;
- менять порядок кнопками «Вверх» и «Вниз»;
- разрешать запоминание значений списочных полей;
- импортировать и экспортировать `fields.json`;
- восстановить заводской набор.

Description не сохраняет историю независимо от настроек.

## Редактирование сохранённых значений

Для списочного поля нажмите `…` справа от редактора. Тот же диалог доступен через «Настроить» → выбрать поле → «Значения…».

Диалог позволяет добавлять, изменять, удалять и очищать значения. Пустые элементы и дубликаты без учёта регистра не сохраняются. Настройки находятся в `%APPDATA%\InvPropTab\fields.json`.

## Сборка

```text
dotnet build "Inv_Property_Tab/Inv_Property_Tab.slnx" -c Release
```

Путь к `Autodesk.Inventor.Interop.dll` задаётся свойством MSBuild `Inventor2020PublicAssemblies`. Обычная сборка не устанавливает add-in. Для разработки доступна отдельная цель `DeployInventor2020Addin`.

## Сборка установщика

```text
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" "installer\InvPropTab.iss"
```

Результат создаётся в `installer/output`.

## Диагностика

Журнал: `%APPDATA%\InvPropTab\invproptab.log`.
